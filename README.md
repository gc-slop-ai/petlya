# Петля

Пошаговая головоломка про петли времени. HTML + Canvas, без зависимостей.

**Играть:** https://gc-slop-ai.github.io/petlya/

Каждый твой проход записывается. Замкни петлю (`E`) — и время отмотается к началу, а прошлый ты станет **эхом**:
он повторит те же нажатия клавиш, ход в ход, и исчезнет, когда закончится его петля.
Эхо держит плиты, открывает двери и пропускает тебя дальше.

- Цветные двери открыты, пока нажата плита того же цвета.
- Штрихованные двери — наоборот: закрыты, пока плита нажата.
- Эхо повторяет **нажатия**, а не путь: если в прошлый раз дверь была закрыта, а теперь открыта — эхо пройдёт.

| Клавиша | Действие |
|---|---|
| ←↑↓→ / WASD | шаг |
| Пробел | ждать |
| E / Enter | замкнуть петлю |
| Z / Backspace | отмена |
| R | уровень заново |

`engine.js` — детерминированный движок: всё состояние выводится из записанных петель, поэтому отмена и прогноз будущего эха — это просто повторная симуляция.
